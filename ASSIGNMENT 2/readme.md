# Program Functionality Description

## 1. Even or Odd Checker
- Input: a single integer entered by the user.
- Functionality: determines whether the entered integer is even or odd by checking the remainder when divided by 2.
- Output: prints a message stating whether the number is even or odd (e.g., "8 is an even number" or "7 is an odd number").

## 2. Sum of Integers from 1 to 50
- Input: none required from the user.
- Functionality: uses a loop to compute the sum of all integers from 1 through 50 (inclusive).
- Output: prints the final sum (e.g., "The sum of number from 1 to 50 is: 1275").
