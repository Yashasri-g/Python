## README Rules

- README.md must have these sections: Overview, Folder Structure,
  Topics Covered, How to Run, and a per-file summary table
- Update the folder structure tree whenever new folders/files are added
- Each file entry in the table must have: filename, folder,
  what it does, and key Python concepts demonstrated

- Create docs/LEETCODE.md with a table of all Leetcode problems:
  problem name, difficulty if known, and approach used
